## Tailored resumes — the rules

Tailored variants live in [`Tailored/`](Tailored/) using the naming format:

```
AkshayPatwari_8years_<applying_company_name>
```

e.g. [`Tailored/AkshayPatwari_8years_Zscaler.md`](Tailored/AkshayPatwari_8years_Zscaler.md).

**What gets changed when tailoring to a JD:**
- ✅ **Objective / summary** — re-pointed at the target role.
- ✅ **Experience bullet emphasis / wording** — surface the JD-relevant work first (kept truthful).
- ❌ **Skills section is NEVER changed for JD matching** — it stays identical to the base resume.
- ❌ Contact, education, achievements, awards — unchanged.

> Only *relevant fields* are updated; the underlying skill set is preserved exactly as on the
> base resume.

## Workflow

1. Keep `Akshay-Patwari-Staff-Engineer.md` as the master; update it whenever the base resume
   changes (then replace the PDF too).
2. For a new application, copy the base into `Tailored/AkshayPatwari_8years_<Company>.md` and
   tune only the objective + bullet emphasis per the rules above.
3. Export to PDF/DOCX for submission (keep single-column, standard headings, no graphics for ATS).
