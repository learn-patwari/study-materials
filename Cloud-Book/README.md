# Cloud Computing — The Book 📘

### *From "why do we even need this?" to your first app running in the cloud — for free.*

---

Welcome. This is a short, friendly **book** about cloud computing. It doesn't assume you know
anything about servers, data centers, or AWS. It starts with a simple question — *why does
the cloud exist at all?* — tells the story of the problems it solves, then walks you all the
way to **creating a free AWS account and deploying your first project with your own hands.**

Read it front to back like a book. Each chapter ends with **Key Takeaways** and a **What's
Next →** link to the following chapter.

## 🎯 How to read this book

- **Total beginner?** Start at Chapter 1 and go in order. By Chapter 7 you'll have deployed
  real things.
- **Just want hands-on?** Skim Chapters 1–4, then jump to **[Chapter 6](06-Free-Tier-Setup-Guide.md)**
  and **[Chapter 7](07-Hands-On-Labs.md)**.
- **Want depth after this?** Two companion references live in this repo:
  - [`Cloud-Computing-Study-Guide.md`](../Cloud-Computing-Study-Guide.md) — deeper concepts and
    real-world architecture scenarios.
  - [`AWS-IAM-Interview-Prep.md`](../AWS-IAM-Interview-Prep.md) — a deep dive on identity &
    security (IAM) and interview preparation.
